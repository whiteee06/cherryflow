# 🍒 CherryFlow OS – AI-Powered Business Operating System

CherryFlow OS is an enterprise-grade, all-in-one business management platform engineered for small businesses, creative agencies, consulting firms, and ambitious freelancers. Powered by **Google Gemini 3.6 Flash AI** and **Supabase**, CherryFlow unifies CRM pipeline management, task tracking, meeting notes, automated invoicing, AI client outreach, team collaboration, and real-time business telemetry in a single, high-performance application.

---

## 🌟 Key Functional Modules

- **📊 Strategic Business Dashboard**: Real-time revenue analytics, deal velocity conversion charts, priority action lists, and recent activity logs.
- **🤝 CRM & Pipeline Management**: Visual Kanban deal pipeline, multi-filter customer table, deal value forecasting, and 1-click AI Outreach Email generation.
- **✅ Task & Project Management**: Interactive task cards, priority indicators, subtask breakdown, due date tracking, and automated task breakdowns powered by Gemini AI.
- **📝 Meeting Notes & Knowledge Base**: Rich note editor with tags, pinning, search, and instant executive summaries generated by AI.
- **🤖 Gemini AI Copilot & Streaming Assistant**: Conversational AI advisor with streaming SSE responses, customizable system prompts, and context-aware business strategy.
- **⚡ Workflow Automation Engine**: Event-driven automation builder for lead assignment, status transitions, email notifications, and webhook triggers.
- **💳 Invoicing & Subscription Billing**: Plan tiers, invoice generation, tax address configuration, and payment gateway simulation.
- **👥 Team Collaboration & Workspace Permissions**: Role-based access control (Owner, Admin, Member, Guest), invitation tokens, member management, and workspace switching.
- **🛡️ Super Admin Governance & DevOps**: Account impersonation, system feature flags, live server metrics, S3 backup triggers, and security headers monitor.

## 🚀 Quick Start (Local Development)

### Prerequisites
- **Node.js**: v20.x or higher
- **npm** or **bun**

### Installation Steps

1. **Clone & Install Dependencies**:
   ```bash
   git clone https://github.com/your-org/cherryflow-os.git
   cd cherryflow-os
   npm install
   ```

2. **Configure Environment Variables**:
   Copy `.env.example` to `.env` and fill in your keys:
   ```bash
   cp .env.example .env
   ```
   Set `GEMINI_API_KEY`, `VITE_SUPABASE_URL`, and `VITE_SUPABASE_ANON_KEY`.

3. **Start Development Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Execute Automated Test Suite**:
   ```bash
   npm test
   ```

5. **Type Check & Lint**:
   ```bash
   npm run lint
   ```

## 🔒 Security & Compliance Features

- **Content Security Policy (CSP)**: Strict script-src and connect-src restrictions.
- **HSTS Enforcement**: `max-age=63072000; includeSubDomains; preload` header enabled.
- **Rate Limiting**: Integrated memory-store limiting client IPs to 300 requests per 15 mins.
- **Anti-XSS & Anti-Clickjacking**: `nosniff`, `SAMEORIGIN`, and clean output sanitization.
- **Server-Side API Keys**: Gemini API key is isolated on the backend server (`server.ts`).
